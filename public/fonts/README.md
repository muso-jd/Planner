# Noto Sans Mono

Source: https://github.com/google/fonts/tree/main/ofl/notosansmono
Original: NotoSansMono[wdth,wght].ttf, retrieved 2026-10-16.
License: SIL Open Font License 1.1, retained in OFL.txt.

The bundled variable WOFF is subset using fontTools to U+0020–024F, U+2000–206F, U+20AC, U+2192 and U+2197. It is stored as base64 text for the embedded Worker asset build. The browser receives normal binary WOFF from the same origin. Font-display: swap preserves immediate text rendering.
